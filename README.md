# JavaScript Ödev 8 — Görsel Galerisi

JavaScript ile dinamik oluşturulan dokuz görsellik galeri. Görsellere tıklanınca
basicLightbox ile büyük görsel açılır. Pencere Escape tuşuyla veya arka plana
tıklayarak kapanır. Galeri, mobil ekranlara uyum sağlar.

## Çalıştırma

`index.html` dosyasını tarayıcıda veya VS Code Live Server ile açın.
Görseller ve CDN üzerinden yüklenen basicLightbox için internet bağlantısı gerekir.

## Dosyalar

- `index.html`: Galeri kapsayıcısı ve CDN bağlantıları.
- `css/styles.css`: Galeri düzeni ve responsive stiller.
- `js/gallery.js`: Görsel verileri, olay delegasyonu ve modal yönetimi.

## Yayınlama

Dosyaları GitHub deposuna gönderdikten sonra **Settings → Pages** bölümünde
**Deploy from a branch**, `main` ve `/ (root)` seçilerek yayınlanabilir.
